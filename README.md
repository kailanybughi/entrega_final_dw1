# entrega_final_dw1

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar e consolidar meus conhecimentos em front-end e back-end, explorando diferentes tipos de componentes visuais e estruturas de navegação.

Embora ainda não esteja totalmente funcional, ele foi muito importante para meu aprendizado, principalmente na construção da estrutura visual de páginas e na organização de elementos interativos.

## Objetivo

A proposta do projeto foi criar uma aplicação com foco em pontos turísticos, apresentando informações como:

- nome do local
- cidade
- curiosidades sobre cada ponto turístico

Além disso, o projeto também foi usado como espaço de testes para aplicar conceitos de interface, organização visual e exibição de dados.

## O que foi desenvolvido

Durante o desenvolvimento, trabalhei com diferentes recursos para testar meus conhecimentos em várias áreas, como:

- estruturação de páginas com HTML
- estilização com CSS
- interatividade com JavaScript
- criação de carrossel de fotos
- montagem de tabela dinâmica
- construção de gráficos em diferentes formatos

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Observações

Este projeto não está finalizado e ainda não possui funcionamento completo no back-end. O foco principal foi explorar a parte visual, testar componentes e praticar a construção de interfaces e recursos dinâmicos.

## Aprendizados

Com esse projeto, consegui praticar e reforçar conhecimentos em:

- desenvolvimento de interfaces
- organização de conteúdo visual
- exibição dinâmica de informações
- testes com gráficos e tabelas
- criação de layouts voltados para navegação e apresentação de dados

## Estrutura do projeto

O projeto contém diferentes páginas e testes visuais, incluindo:

- cadastro
- carrossel
- tabela dinâmica
- gráficos em diferentes formatos
